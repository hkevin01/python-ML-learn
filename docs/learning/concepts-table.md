

# 📊 **10 Classical ML Algorithms — When to Use + 4‑Word Descriptions**

| Algorithm | When to Use | Four‑Word Description |
|----------|-------------|------------------------|
| **Linear Regression** | Continuous target, linear relationships, fast baseline modeling | *Simple, interpretable, fast, foundational* |
| **Logistic Regression** | Binary classification with probabilities and interpretability | *Probabilistic, stable, explainable, efficient* |
| **k‑Nearest Neighbors (KNN)** | Small/medium datasets, similarity‑based classification | *Instance‑based, intuitive, local, flexible* |
| **Naive Bayes** | Text classification, high‑dimensional sparse data | *Probabilistic, lightweight, scalable, surprising* |
| **Decision Trees** | Need interpretability, non‑linear relationships | *Visual, rule‑based, branching, intuitive* |
| **Random Forest** | General‑purpose strong baseline for most tasks | *Ensemble, robust, reliable, versatile* |
| **Support Vector Machines (SVM)** | High‑dimensional data, clear class boundaries | *Margin‑maximizing, powerful, geometric, precise* |
| **k‑Means Clustering** | Unsupervised grouping, customer segmentation | *Iterative, centroid‑driven, exploratory, simple* |
| **PCA** | Dimensionality reduction, noise removal, visualization | *Orthogonal, compressive, variance‑focused, elegant* |
| **Gradient Boosting (GBM)** | Maximum accuracy, structured/tabular data | *Sequential, corrective, competitive, high‑performing* |
